# UI / UX

## Главное меню

- Dashboard
- Торговые точки
- Сотрудники
- Задачи
- Смены
- Отчеты
- Настройки

## Экран сотрудников

Карточка сотрудника должна содержать:

- ФИО
- Логин
- Цветные флажки точек
- Кнопки: изменить пароль, уволить, задачи, смены

## Экран торговых точек

Карточка точки должна содержать:

- цветной флажок
- название
- адрес
- метро

## Экран авторизации

- Логин
- Пароль
- Кнопка "Забыли пароль?"
- При наведении на ссылку эффект hover
- При клике показывается окно с контактами администратора

## Дизайн

- Минимализм
- Material 3
- Плавные анимации
- Hover-эффекты
- Карточки и плавные переходы
