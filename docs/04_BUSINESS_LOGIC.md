# Business Logic

## Роли

### Администратор

- Управляет точками
- Управляет сотрудниками
- Создает и назначает задачи
- Смотрит отчеты
- Меняет пароли сотрудников

### Сотрудник

- Видит свои задачи
- Видит смены
- Сдает отчеты

## Смена

- Дневная: 10:00 — 22:00
- Ночная: 22:00 — 10:00

## Отчеты

- После смены сотрудник сдает отчет
- Администратор видит выполено / не выполнено
- Есть подробный список задач
