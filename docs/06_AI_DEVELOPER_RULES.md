# AI Developer Rules

- Никогда не присылай куски файла.
- Всегда присылай полный файл.
- Перед изменением анализируй существующий файл.
- Не удаляй рабочую логику.
- После каждого изменения проект должен компилироваться.
- Не менять архитектуру без причины.
- Не создавать дублирование.
- Не писать TODO.
- Не писать временный код.
- Следовать Repository Pattern.
- Следовать Material 3.
- Не ломать существующую бизнес-логику.
- Использовать современные практики Flutter.
- Соблюдать структуру папок и именование.
