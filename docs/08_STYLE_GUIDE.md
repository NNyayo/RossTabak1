# Style Guide

## Именование

- Файлы: snake_case
- Классы: PascalCase
- Переменные и методы: camelCase
- Константы: PascalCase

## Структура файлов

- `employee_repository.dart`
- `store_repository.dart`
- `add_employee_page.dart`

## Код

- Использовать 2 пробела для отступов
- Избегать длинных строк
- Писать понятные имена
- Выносить повторяемую логику в методы
- Соблюдать порядок импортов
