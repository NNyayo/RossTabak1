# Project Overview

RossTabak Manager — это профессиональная CRM-система для управления сетью торговых точек.

## Цель проекта

Создать масштабируемое настольное приложение под macOS для управления торговыми точками, сотрудниками, задачами, сменами и отчетами.

## Для кого

- Администраторы сети торговых точек
- Руководители по продажам и логистике
- Менеджеры, отвечающие за назначение задач и контроль выполнения

## Задачи, которые решает проект

- Управление торговыми точками
- Управление сотрудниками и их рабочими точками
- Привязка задач к сотрудникам и точкам
- Ведение отчетов по сменам и выполнению задач
- Надёжная авторизация и разделение прав доступа

## Принципы работы

- Минималистичный интерфейс на Material 3
- Четкая архитектура с разделением ответственности
- База данных SQLite для локального хранения
- Репозиторный слой для доступа к данным
- Готовность к расширению на Windows и далее на Android/iOS
