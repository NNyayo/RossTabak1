# 🪟 Rosstabak Manager — установщик для Windows

## Как собрать установщик на Windows (5 минут)

### Шаг 0. Как открыть командную строку в папке

На Windows есть **3 способа**:

**Способ А — самый простой (рекомендую):**
1. Открой папку `rosstabak_manager` через проводник
2. Кликни **правой кнопкой мыши** по пустому месту в папке (не по файлу!)
3. В меню выбери **"Открыть в терминале"** (или **Open in Terminal**)

**Способ Б — через адресную строку:**
1. Открой папку `rosstabak_manager` через проводник
2. Нажми на адресную строку сверху (там написано путь, например `C:\Users\...`)
3. Сотри всё, напиши `cmd` и нажми **Enter**

**Способ В — через Пуск:**
1. Нажми `Win + R` → напиши `cmd` → Enter
2. В открывшемся окне напиши:
```cmd
cd /d C:\путь\к\rosstabak_manager
```
(путь должен быть тот, где лежит папка с программой)

---

### Шаг 1. Установи Flutter

Скачай Flutter: https://docs.flutter.dev/get-started/install/windows

После установки открой **командную строку** (любым способом выше) и проверь:
```cmd
flutter doctor
```
Если всё зелёное — идём дальше.

### Шаг 2. Перенеси код на Windows

Скопируй папку `rosstabak_manager` с Mac на Windows (через флешку, облако или по сети).

### Шаг 3. Собери программу

Открой **командную строку в папке `rosstabak_manager`** (способ А из Шага 0) и выполни по очереди:

```cmd
flutter pub get
```

```cmd
flutter build windows --release
```

Готовый `.exe` будет здесь:
```
rosstabak_manager\build\windows\x64\runner\Release\rosstabak_manager.exe
```

### Шаг 4. Создай установщик (для иконки на рабочем столе)

1. Скачай **Inno Setup**: https://jrsoftware.org/isdl.php
2. Установи его
3. Открой **командную строку в папке `rosstabak_manager`** и выполни:

```cmd
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" build\windows\installer\installer.iss
```

Готовый установщик появится в папке `installer_output\`:
```
RosstabakManager_Setup_1.0.0.exe
```

### Шаг 5. Положи файл в проект

Скопируй `RosstabakManager_Setup_1.0.0.exe` в папку `release\windows\` внутри проекта.

---

## ✅ Готово!

Теперь любой человек с Windows:
1. Открывает папку `release/windows/`
2. Нажимает на `RosstabakManager_Setup.exe`
3. Нажимает "Далее" → "Далее" → установка
4. Иконка программы появляется на рабочем столе → можно запускать

**Никакого дополнительного софта не нужно.** Всё необходимое уже внутри установщика.
