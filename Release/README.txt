О ПРОГРАММЕ
-----------
Rosstabak - это система управления задачами и сменами
для магазинов компании Rosstabak.

Функции:
- Управление сотрудниками
- Управление торговыми точками
- Создание и назначение задач
- Управление сменами
- Статистика и отчеты
- Система уведомлений

СИСТЕМНЫЕ ТРЕБОВАНИЯ
--------------------
macOS: macOS 11 (Big Sur) или новее
Windows: Windows 10 или новее

УСТАНОВКА (macOS)
-----------------
1. Откройте файл Rosstabak.dmg
2. Перетащите иконку Rosstabak в папку Applications
3. Запустите программу из папки Applications

При первом запуске может появиться предупреждение
системы безопасности. Для запуска:
- Нажмите правой кнопкой мыши на программу
- Выберите "Открыть"
- Нажмите "Открыть" в диалоговом окне

УСТАНОВКА (Windows)
-------------------
1. Запустите файл Rosstabak_Setup.exe
2. Следуйте инструкциям установщика
3. Ярлык программы появится на рабочем столе

УДАЛЕНИЕ (macOS)
----------------
1. Откройте папку Applications
2. Перетащите Rosstabak в Корзину

УДАЛЕНИЕ (Windows)
------------------
1. Откройте Панель управления > Программы и компоненты
2. Выберите Rosstabak
3. Нажмите "Удалить"
